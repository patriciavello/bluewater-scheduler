# Bluewater Scheduler

Regular User Manual

Version 1.0

April 21, 2026

## Purpose

This manual explains how regular users can use the Bluewater Scheduler to create an account, request boat reservations, book scheduled events, manage profile information, and review reservation or payment details.

Use this manual for customer-facing workflows. Administrative, supervisor, technician, and back-office workflows are intentionally not covered here.

## Before You Start

- Web address: https://bluewater-scheduler.onrender.com/account
- Use a modern web browser such as Chrome, Safari, Edge, or Firefox.
- Have your email address, phone number, and password ready.
- Sign in before requesting a reservation or booking an event.
- Standard users may be redirected to secure card payment before a reservation is created.
- Gold members can submit reservation requests directly for office review.

## Main Navigation

The regular user experience is organized around three main areas:

- Home schedule: search boat availability and request a reservation.
- Experiences: view flotillas, sailing tours, and training events.
- My Account: sign in, manage profile details, review reservations, review events, and change your password.

From the home page, use My Account to sign in or manage your account. Use Experiences to browse fixed-date events. Use the Bluewater Escapes brand link to return to the main schedule.

## Create an Account

1. Open My Account.
   You can go directly to https://bluewater-scheduler.onrender.com/account.
2. Select Create account.
3. Enter your email address.
4. Enter your phone number.
5. Enter a password with at least 8 characters.
6. Select Create account.

After registration, the system signs you in automatically and opens your account area.

## Sign In

1. Open My Account.
   You can go directly to https://bluewater-scheduler.onrender.com/account.
2. Select Sign in.
3. Enter your email address and password.
4. Select Sign in.

If you forgot your password, use the Forgot password link on the sign-in form.

## Search Boat Availability

The home schedule shows a 14-day availability view.

1. Open the home page.
2. Optional: choose a Start date.
3. Optional: enter a Duration in days.
4. Optional: select one or more boats under My boats to narrow the schedule.
5. Review the schedule grid.

Schedule labels:

- Open means the boat can be requested for that date.
- Booked means the boat is not available.
- Event means the boat is reserved for a fixed-date event.

Use Past and Future to move the 14-day schedule backward or forward.

## Request a Boat Reservation

1. In the schedule grid, click an Open date for the boat you want.
2. Review the boat details, including capacity, beds, boat type, start day, duration, and price.
3. Add optional notes.
4. Select Request reservation.

If you are not signed in, the system sends you to My Account first.

Gold members submit the request directly. Standard users may be sent to secure card payment before the reservation is created.

## Understand Reservation Status

Reservation status appears in My Account under My reservations.

- Pending: the request has been submitted and can still be changed or cancelled by the user.
- Approved: the reservation has been approved. Changes require a request, may include a fee, and need office approval.
- Change requested: a change request has been submitted and is waiting for office review.
- Cancelled: the reservation was cancelled.
- Past reservation: the reservation has already occurred.

## View Your Reservations

1. Open My Account.
2. Sign in if needed.
3. Select My reservations.
4. Review reservation dates, status, payment information, refund information, net paid amount, and notes.

Use Hide past reservations to focus on current and upcoming reservations.

## Change or Cancel a Pending Reservation

Pending reservations can be edited directly.

1. Open My Account.
2. Select My reservations.
3. Find the pending reservation.
4. Change the start date or duration.
5. Select Change my reservation.

To cancel a pending reservation, select Cancel reservation and confirm the prompt.

## Request a Change to an Approved Reservation

Approved reservations cannot be directly changed by the user.

1. Open My Account.
2. Select My reservations.
3. Find the approved reservation.
4. Enter the requested new start date and duration.
5. Add a justification for the change.
6. Accept the applicable change fee notice.
7. Select Request change.

The request is sent for office review. The reservation will show a change-requested status while it is pending.

## Book an Event

Events are fixed-date experiences such as flotillas, sailing tours, and training events.

1. Open Experiences.
2. Review the available events.
3. Select View Event.
4. Review the boat, date range, available spots, description, and available packages.
5. Select Book This Option for the package you want.

Event dates are fixed and cannot be changed during booking. If the event or package is full, the button shows Sold Out.

## View Event Bookings

1. Open My Account.
2. Select My Events.
3. Review event title, event type, boat, date range, package, participants, booking status, and amount.
4. Select View Event to return to the event detail page.

## Manage Your Profile

1. Open My Account.
2. Select Profile.
3. Update your contact details:
   - First name
   - Last name
   - Phone
   - Address
   - City
   - State
   - ZIP
   - Country
4. Select Save changes.

Keeping your profile current helps the office contact you about reservations, approvals, events, payments, or schedule changes.

## Change Your Password

1. Open My Account.
2. Select Password.
3. Enter your current password.
4. Enter your new password.
5. Select Update password.

Use a password that is unique to this account.

## Payments and Refund Details

When payment information exists, My reservations shows:

- Payment status.
- Paid amount.
- Payment date.
- Refund status.
- Refunded amount.
- Refund date.
- Net paid amount.

If a standard user is redirected to secure card payment, follow the payment page instructions. After payment, return to My Account to review the reservation.

## Troubleshooting

- If the schedule does not load, refresh the page and try again.
- If a reservation request asks you to sign in, open My Account and sign in first.
- If an event booking says Please sign in, sign in and return to the event.
- If a date is unavailable, choose another Open date or move the schedule using Past or Future.
- If you cannot edit a reservation, check its status. Approved reservations require a change request.
- If payment or refund information looks incorrect, contact the office.

## Quick Reference

- New boat reservation: Home schedule -> Open date -> Request reservation.
- Event booking: Experiences -> View Event -> Book This Option.
- View reservations: My Account -> My reservations.
- View event bookings: My Account -> My Events.
- Update contact details: My Account -> Profile.
- Update password: My Account -> Password.
- Return to schedule: Bluewater Escapes.
